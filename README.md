# Java OOP Shapes Project

## About
A simple Java console application that demonstrates Object-Oriented Programming (OOP) concepts through geometric shapes.

## Features
- Calculate the area and perimeter of a circle.
- Calculate the surface area, perimeter, and volume of a cube.
- Use abstraction, inheritance, interfaces, encapsulation, and method overriding.
- Calculate the total area of multiple circles and cubes.

## Technologies
- Java
- Object-Oriented Programming (OOP)

## Project Structure
- `Main.java` — Reads input and calculates the total area.
- `Shape.java` — Abstract base class for shapes.
- `ThreeDShape.java` — Abstract class for three-dimensional shapes.
- `Drawable.java` — Interface defining the drawing description.
- `Circle.java` — Implements circle calculations.
- `Cube.java` — Implements cube calculations.

## How to Run
1. Open the project in a Java IDE.
2. Run `Main.java`.
3. Enter 10 numbers for circle radii, followed by 10 numbers for cube side lengths.
4. The application prints the total area.

## Learning Outcomes
Practiced Java OOP concepts, class relationships, abstract classes, interfaces, and method overriding.
